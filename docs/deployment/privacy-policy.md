# 账页核对隐私政策

适用于 0.1.1 免费验证版。

点击「读取当前页」后，扩展读取当前主页面已渲染标准 HTML 表格中的表头和文本。选择期别后，保存该表格、站点来源（协议与主机）、表格名称及时间。导入 CSV 时处理文件的表格文本、文件名和导入时间。你可以主动保存核对规则。

台账、规则和核对结果由本机浏览器处理。扩展没有账户、遥测、服务器上传或向第三方共享数据的功能。保存的数据在当前浏览器的扩展本地存储中。

数据管理可以导出 JSON 备份、删除一期或清除全部数据。核对结果可以导出 Excel。保存到电脑的导出文件独立于扩展，用户自行管理。卸载扩展会移除其浏览器存储。

临时网页访问权限用于你主动选择的页面，脚本执行权限用于读取当前表格，存储权限用于两期台账和规则。
