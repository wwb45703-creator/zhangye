账页核对 · 免费试用说明

安装与练习
1. 把 ZIP 解压到一个目录。打开 Edge 的 edge://extensions/ 或 Chrome 的 chrome://extensions/。
2. 打开开发人员模式，点「加载解压缩的扩展」，选择解压出来的 extension 文件夹。打开工具栏扩展，选择「打开核对台」。
3. 点击「载入示例」练习查看差异和导出报表。XLSX 可用微软 Excel 或 WPS 表格打开。
4. 如需练习一单多行，分别导入 samples/delivery-before.csv 和 samples/delivery-after.csv。两期主键选「订单编号」，勾选「一单多行，加入明细编号」，上期明细选「明细编号」，本期明细选「分录标识」。勾选三个同名字段后开始核对。预期有 1 项字段变更、1 项仅本期有、1 项本期未见、2 项待复核，以及 2 条无变化。练习数据均为虚构。

没有业务台账时，也可以对照公开案例
https://ggzyfw.beijing.gov.cn/jyxxgzsx/20250723/5197228.html
在公告页分别读取第一张表（更正前）为上期、第二张表（更正后）为本期。选「序号」为主键并核对全部同名字段。应只发现序号 33、34、35 的技术配置改变，其他三类差异为 0。这是公开网页练习，实际岗位的用时与购买条件另行填写。

用实际任务试用
1. 找到同一组织、同一业务范围的两期台账。先确认编号在两期是否一致，每行代表订单还是明细。
2. 按平时的做法核对一次。从拿到两期来源开始计时，到交出可分享的差异清单结束。系统自带查询、现有 Excel 或 Power Query 都可作为基线。
3. 用插件重复同一范围的任务。网页未标记表头时，确认首行确实是列名才存入。系统若只导出 Excel，选择业务工作表并另存为逗号分隔 CSV，优先 UTF-8，核对单号和明细编号的前导零。转换耗时计入插件路径。
4. 核实两份结果。区分字段变化、本期未见、空号和真重号。页面换了筛选或分页时回原系统判断。下周复用时，可先保存规则并将本期转为下一次的上期。
5. 填写 feedback.txt。反馈只需要岗位、用时、结果数量、页面类型及障碍。订单编号、供应商、金额、账号、浏览器截图和导出的业务文件可留在本机。

如已安装旧版，请先在数据管理备份，再用新包安装。导入旧版 JSON 可带入台账及单主键规则。使用明细编号的规则需要 0.1.1 或更新版本。
