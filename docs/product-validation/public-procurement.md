# 公开案例 · 核对采购更正前后的技术配置

可用现有免费试用包操作。验收样本是北京公共资源交易服务平台 2025-07-23 发布的采购文件更正公告，项目编号 S110000C005095814001。公告在同一页分别列出更正前、后两张表，便于按原文查验。[官方公告](https://ggzyfw.beijing.gov.cn/jyxxgzsx/20250723/5197228.html)

1. 按 [安装说明](../../README.md) 加载 0.1.1。已有工作台数据时，可以先从「数据管理」导出备份。
2. 在官方公告页打开工具栏扩展，点「读取当前页」。选择页面顺序中的第一张表作为上期，即公告里的「更正前」。如果提示确认表头，先核对第一列为「序号」。
3. 再读同一页，将第二张表作为本期，即「更正后」。两张表均为 3 条记录、5 列。
4. 打开核对台，选择两期主键「序号」，勾选可核对的同名字段并开始核对。预期只有序号 33、34、35 的「配置要求（技术参数或组件）」变化。新增、未见和待复核均为 0。
5. 打开任意一行的明细，可对照原文。导出 Excel 后查看「差异清单」和「字段前后值」。

## 证据与复测

2026-11-08，本机 Edge 157.0.4341.42、Chrome 154.0.8037.98 从对应的 0.1.1 ZIP 解包加载。均直接读取原站两张表并核对到 3 条技术配置变化。WPS 表格 12.1.0.29690 和原生 Microsoft Excel 16.0.20527.20150 分别打开两款浏览器下载的报表，前后共 6 个文本值与网页原表逐个一致。测试范围为该公告的两张表。

```powershell
npm.cmd run test:public
npm.cmd run test:public -- --microsoft
```

运行需要已构建的 ZIP、本机 Chrome、Edge 和可自动化的表格程序，以及正常访问官方公告。可用 `npm.cmd run test:public -- edge` 只测 Edge。脚本使用隔离浏览器配置，读取网页后临时导出报表并核对原值。

另两个真实页面在 Edge 中可读。吉林敦化的表为 17 条 × 4 列，和田的表为 15 条 × 4 列。两页已把更正前后放在同一张表，打开公告即可查看，业务价值与北京两份表的练习分开判断。[吉林公告](https://www.jl.gov.cn/ggzy/ybzggzy/ybzjyxx/ybzzfcg/ccszcbggg/202601/t20260128_9408732.html) · [和田公告](https://ggzy.ht.gov.cn/jyxx/001004/001004002/20260804/c0b76b56-f344-4b44-8a28-063810281797.html)

这些结果只覆盖相应的公开采购表格。使用自己的两期台账时，可按 [使用说明](../../README.md#使用说明) 确认主键、表格范围与差异结果。
